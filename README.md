# Cilveli priv mod
Minecraft 1.20.1 Fabric istemci eklentisidir. F4 tuşuna başarak görünmezleri görmeyi (Ghost veya Glow efektiyle) etkinleştirebilirsiniz. Stealth Mode (Sessiz Mod) desteği ile kontrollerde tamamen yasal ve gizli bir eklenti gibi çalışır. ModMenu desteğiyle kişiselleştirilebilir.
